# cmark-gfm-go

This is a golang binding for cmark-gfm. I forked [github/cmark-gfm][link1] and
add a golang binding for it.

The golang part is based on [rhinoman/go-commonmark][link2], I copy them from
[b6e895a10][link3].

[link2]: https://github.com/rhinoman/go-commonmark
[link3]: https://github.com/rhinoman/go-commonmark/commit/b6e895a10b0824338d2040e715cb809eb3cb5e44
